# 🛒 CartLane

### A Modern E-Commerce Shopping Experience

CartLane is a modern e-commerce web application inspired by popular online shopping platforms. Built with modern web technologies, it focuses on a clean user interface, responsive design, smooth interactions, and a convenient shopping experience.

## ✨ Features

- 🏠 **Home Page** — Modern shopping homepage with product categories and featured products.
- 🔍 **Product Search** — Search and discover products easily.
- 🗂️ **Product Categories** — Browse products by category.
- 🎛️ **Product Filtering & Sorting** — Find products based on different preferences.
- 📦 **Product Details** — Dedicated pages with product information and pricing.
- 🛒 **Shopping Cart** — Add, remove, and manage cart items.
- ❤️ **Wishlist** — Save favorite products for later.
- 🔐 **Demo Authentication** — Demonstration sign-in and account experience.
- 💳 **Checkout Experience** — Interactive demo checkout flow.
- 📋 **Order History** — View previously placed demo orders.
- 🏷️ **Coupons & Discounts** — Demonstration promotional offers.
- 👨‍💼 **Admin Interface** — Administrative features for the demo application.
- 📱 **Responsive Design** — Optimized for desktop, tablet, and mobile screens.
- 🎨 **Modern UI** — Clean layouts, reusable components, and consistent styling.

## 🛠️ Tech Stack

- **Framework:** Next.js
- **Library:** React
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Package Manager:** npm
- **Storage:** Browser Local Storage for demo data

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/) — LTS version recommended
- npm — included with Node.js
- [Visual Studio Code](https://code.visualstudio.com/) — recommended editor

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/CartLane-Ecommerce.git
```

**2. Open the project directory**

```bash
cd CartLane-Ecommerce
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Visit [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

To create a production build, run:

```bash
npm run build
```

To start the production server after a successful build:

```bash
npm run start
```

## 🔒 Demo & Security Notes

- Authentication and checkout are designed for demonstration purposes.
- Demo data may be stored in browser Local Storage.
- This project is not intended for processing real payments or storing sensitive customer information.
- Production deployment would require secure authentication, server-side data storage, payment integration, and appropriate security measures.
